Backup e restauração

Exporte seus dados para migrar entre dispositivos ou como backup. O arquivo JSON contém todo o histórico e recordes.

Publicar na internet

Opção A — GitHub Pages (gratuito)

1. Crie uma conta em github.com
2. Clique em New repository → nomeie meu-treino
3. Marque Public e Add README
4. Faça upload do index.html
5. Vá em Settings → Pages → Branch: main
6. Acesse: seu-usuario.github.io/meu-treino

Opção B — Netlify Drop (mais rápido)

1. Acesse app.netlify.com/drop
2. Arraste o arquivo index.html para a área de drop
3. Você recebe um link como abc123.netlify.app na hora
4. Crie conta para personalizar a URL

Opção C — Uso local (mais simples)

Abra o index.html diretamente no navegador do celular. Os dados são salvos no LocalStorage do dispositivo. Use Exportar/Importar JSON para sincronizar entre aparelhos.
